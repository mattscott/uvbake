# Security Policy

## Supported versions

Only the latest commit on `main` receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting instead:
**Security → Report a vulnerability** on
[this repository](https://github.com/mattscott/uvbake/security/advisories/new).

Include the version or commit, a description of the problem, and a file that reproduces it if you
can. UVBake parses untrusted mesh files, so crashes, hangs or excessive memory use on malformed input
are in scope. You should get an acknowledgement within a few days.
